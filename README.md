# Доставка драников: Киберпанк Гродно

8-битный веб-раннер на чистом HTML5 Canvas API и Web Audio API — без библиотек и внешних ассетов. Курьер на электросамокате мчит через неоновую ночь, перепрыгивает дорожные ямы, заборы и курьеров-конкурентов из Yandex Доставки в жёлтых рюкзаках, а ещё закидывает горячими драниками голодных прохожих у ЕВРООПТа.

Экран стилизован под старый ЭЛТ-телевизор: сканлайны, выпуклый кинескоп, виньетка.

## Играть

Открой `index.html` в браузере — ничего устанавливать не нужно. Либо играй онлайн через GitHub Pages (ссылка появится после публикации).

## Скачать и запустить локально

1. Скачай репозиторий: кнопка **Code → Download ZIP** на странице репозитория (или `git clone` для тех, кто предпочитает консоль).
2. Распакуй архив.
3. Открой `index.html` двойным кликом — игра запустится прямо в браузере.

## Управление

- `ArrowUp` / `W` / `Пробел` — прыжок через яму.
- `E` / `Enter` — бросить коробку горячих драников вперёд.

## Механика

- **ЕВРООПТ** — попади драником в человека рядом с магазином: **+500 BYN**.
- **МІЛА** — проезд мимо магазина даёт розовый щит, спасающий от одного препятствия.
- **ГЕММА** — лови золотые мешки картошки: **+5 драников** (это же боезапас для бросков).
- На дороге три вида препятствий — ямы, заборы и курьеры-конкуренты в жёлтых рюкзаках. Столкновение без щита — Game Over.
- Маршрут проходит через районы Гродна (Стары горад, Новы Свет, Лососна, Альшанка, Румлёва), которые сменяются по мере проезда — у каждого своя палитра неба и домов, плотность деревьев/фонарей.

## Технологии

`HTML5 Canvas API` и `Web Audio API`. Фоновый chiptune-саундтрек и все звуковые эффекты сгенерированы программно (`square`/`triangle` осцилляторы + шумовой буфер для взрыва) — без единого аудиофайла.
